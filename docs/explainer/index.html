What is gemini-activity-harvester and what is it like to use?

Long image

A

Answer

It is a Python command-line tool that reads your own Google Gemini prompt history. It flags prompts where you asked for a skill, prompt tool or bot, and tells you which ones you have not built yet. It is a working prototype for macOS and Chrome, tuned to its author's projects.

  1. You feed it your Gemini history, either live from a Chrome tab or as text copied from My Activity.1
  2. A keyword rule table sorts each prompt into a type and suggests a project name.2
  3. It checks each name against folders in a workspace and against gh repo list, then marks it new or duplicate.3
  4. You get a JSON report plus a printed list of new candidates. It does not build the projects for you.4

  1. Open My Activity or copy text ↗

    For a live scrape, keep myactivity.google.com/product/gemini open in Google Chrome on macOS. Otherwise save copied activity text to a file.

  2. Run scrape or scan ↗

    scrape (or run) drives Chrome through AppleScript; scan and audit read a text file; classify only sorts.

  3. Sort each prompt ↗

    Keyword rules give each prompt a type (skill, prompt_tool, mcp_or_agent_repo or other), a suggested name and a fixed confidence.

  4. Already built? ↗

    The suggested name and a few variants are compared with folder names in the workspace, three skill folders and your GitHub repos.

  5. JSON report + candidate list ↗

    scrape saves scrapes/gemini_activity_<time>.json and prints counts and new candidates; scan prints JSON.

What should you know before relying on it?

Names come from a fixed table

The rules map keywords to the author's own project names, such as baton, openhaul and discord-voice-gemini.2 Any Discord bot becomes discord-voice-gemini, and most skills become agent-skill. Confidence values are constants per rule, not model scores.
